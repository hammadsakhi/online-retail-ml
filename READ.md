# Online Retail Customer Analytics & Machine Learning

An end-to-end Machine Learning project that analyzes online retail customer behavior, predicts repeat purchases, and segments customers based on their purchasing patterns.
## Dashboard Preview

![Online Retail ML Dashboard](screenshots/dashboard.png)

## Project Overview

This project combines supervised and unsupervised Machine Learning with a web dashboard and REST API.

### Key Features

- **Repeat-Purchase Prediction:** Predicts whether a customer is likely to make a repeat purchase.
- **Customer Segmentation:** Uses K-Means clustering to group customers according to their purchasing behavior.
- **Interactive Dashboard:** Displays customer statistics, model performance, prediction metrics, and prediction history.
- **REST API:** Uses FastAPI to serve predictions and retrieve customer prediction records.
- **Database Integration:** Uses PostgreSQL to store and retrieve prediction history.
- **Data Export:** Allows users to download prediction records and segmented customer data as CSV files.

## Machine Learning Models

### Supervised Learning

The repeat-purchase prediction model uses customer purchasing features to predict the target class.

Features:
- Recency
- Frequency
- Monetary
- Total Quantity
- Unique Products

The model returns a predicted class and an estimated probability of repeat purchase.

### Unsupervised Learning

K-Means clustering groups customers into purchasing-behavior segments. A saved scaler transforms customer features before clustering.

The dashboard displays segment counts, average purchasing behavior, and cluster visualizations.

## Application Architecture

1. Customer features are provided to the prediction interface.
2. Streamlit sends prediction requests to the FastAPI backend.
3. FastAPI loads the trained model and generates a prediction.
4. Prediction results are stored in PostgreSQL.
5. FastAPI returns the prediction response to Streamlit.
6. The dashboard retrieves prediction history and statistics through API endpoints.

## API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/predict` | Generate and save a prediction |
| GET | `/predictions` | Retrieve prediction history |
| GET | `/customers` | Retrieve customer records |
| GET | `/prediction-stats` | Retrieve prediction statistics |

The `/predictions` endpoint optionally accepts a `customer_id` query parameter.

Interactive API documentation is available at `/docs` when the FastAPI server is running.

## Running the Project

### 1. Install dependencies

Create and activate a Python virtual environment, then install the project's required packages.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Install dependencies from your project's requirements file:

```bash
python -m pip install -r requirements.txt
```

### 2. Configure PostgreSQL

Create the PostgreSQL database and configure the database connection in your local `.env` file using the variable names expected by the backend.

Never commit database passwords or other secrets to GitHub.

### 3. Start FastAPI

Run the Uvicorn command configured for your backend module.

API documentation:

`http://127.0.0.1:8000/docs`

### 4. Start Streamlit

From the directory containing the Streamlit application:

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal.
